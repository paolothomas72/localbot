# Weekly report template

Part 1 is for anyone. Two or three sentences on what was tested, then one table:
model, hardware, what it did well, where it stopped, whether the safety checks held,
what changed since last week, what that means for a person using it, and how to check
(the result file and the command that rebuilds this page).

Part 2 is the evidence for the people who build Local Bot: the commit, the Ollama version,
the GPU, the dates, each gate's bar and time, each model and pack with its score and
efficiency numbers, every miss labelled verified or reported, the file list with sha256,
and what was not tested this week.

A week with no runs says "no runs this week" and does not copy last week's table.
Every number links to the result file it came from.
